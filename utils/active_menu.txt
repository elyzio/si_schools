New Tags for Dropdown Menus:
1. active_app - For dropdown menu styling:
{# Single app - keeps dropdown open when in 'estudante' app #}
<li class="nav-item dropdown {% active_app 'estudante' 'menu-open' %}">
  
{# Multiple apps - activate for multiple related apps #}
<li class="{% active_app 'estudante' 'professor' 'turma' %}">
2. is_active_app - For conditional logic:
{% is_active_app 'estudante' as in_student_section %}
{% if in_student_section %}
  <ul class="dropdown-menu show">
    <!-- Show dropdown when in estudante app -->
  </ul>
{% endif %}
